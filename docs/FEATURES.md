# Features

## Preserved demo features

- Public landing page and legal-framework page.
- Demo authentication for Officer, Manufacturer/Packer, Seller/E-commerce, and Consumer.
- Label upload preview and simulated scan progress.
- Officer dashboards, inspection evidence, finding verification/rejection controls, complaint list, and printable report.
- Manufacturer dashboard, packaging check, and artwork comparison.
- Seller dashboard, listing scan, and bulk-check interface.
- Consumer scan result, complaint submission, and National Consumer Helpline card.

## Current limitation

All records, credentials, OCR results, scores, findings, dashboards, and workflow updates remain mock/demo data until later milestones.

## Milestone 2A foundation

The repository now includes an unconnected Supabase client boundary and version-controlled schema, RLS, and private Storage definitions. These are infrastructure foundations, not live product features; existing demo flows remain mock-backed.
