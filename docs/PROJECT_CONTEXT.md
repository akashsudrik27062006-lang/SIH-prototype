# Project Context

LabelGuard is an SIH 2026 prototype for SIH26034. It helps stakeholders assess packaged-commodity labels under Legal Metrology requirements.

The core principle is: **AI extracts. Rules validate. Evidence explains. Human verifies. System records.**

The four user roles are Manufacturer/Packer/Importer (prevent), Seller/E-commerce (verify), Legal Metrology Officer (enforce), and Consumer (detect and report). The initial repository is a polished client-side demo. Milestone 1 preserved that demo; Milestone 2A adds its Supabase foundation without connecting live workflows.
