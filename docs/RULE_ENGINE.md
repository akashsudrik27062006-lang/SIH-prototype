# Rule Engine Plan

Milestone 2A still keeps only the existing demo finding generator. The `scans.score` foundation column is informational and must never be interpreted as a legal determination.

The future rule engine must be deterministic, versioned, testable, and separate from AI extraction. It should accept normalized extracted declarations and contextual metadata, determine applicable requirements, return pass/warn/fail/potential findings with legal citations, and explain evidence and remediation. AI output is evidence for potential findings, never an automatic legal decision. Officer confirmation, rejection, or modification is required for enforcement outcomes.
